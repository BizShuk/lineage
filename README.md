# 說話之島單機致敬版

這是一款以 2000–2003 年台灣早期《天堂》說話之島為參考的非商業單機角色扮演遊戲。玩家可在桌面瀏覽器建立 `王族`、`騎士`、`妖精` 或 `法師`，從稻草人訓練開始，經歷村莊整備、野外狩獵、黑騎士事件、地監探索與巴風特首領戰，完成篇章後繼續自由探索。

本專案目前處於依核准規格逐步實作的階段。完整業務範圍與驗收標準見[設計規格](docs/specs/2026-07-17-talking-island-single-player-design.md)，實作順序見[實作計畫](plans/2026-07-17-talking-island-implementation.md)。

## 支援環境

- 桌面版 Chromium 瀏覽器；自動化驗收使用 Playwright 所安裝的 Chromium。
- Node.js `24.x`。
- npm `11.x`。
- 遊戲目標為安裝後可離線執行，不包含伺服器、帳號或多人連線。

## 安裝與執行

```bash
npm install
npm run dev
```

開發伺服器啟動後，依終端顯示的本機網址開啟遊戲。

## 建置與驗證

```bash
npm run build
npm run typecheck
npm run lint
npm test
npm run test:e2e
npm run verify
```

`npm run verify` 依序執行 lint、型別檢查、測試、production build 與瀏覽器端到端測試。

## 操作

| 輸入 | 行為 |
| --- | --- |
| 滑鼠左鍵點地面 | 移動至選定位置 |
| 滑鼠左鍵點敵人 | 走至攻擊距離並連續攻擊 |
| 滑鼠左鍵點 NPC／物件 | 接近並互動 |
| `WASD`／方向鍵 | 八方向移動 |
| `Space` | 攻擊最近的有效敵人 |
| `E` | 與最近的 NPC 或物件互動 |
| `Tab` | 依距離切換附近敵人 |
| `F5–F12` | 使用八格快捷列物品或技能 |
| `I` | 開關物品欄 |
| `C` | 開關角色及裝備窗 |
| `S` | 開關魔法／技能窗 |
| `Q` | 開關任務窗 |
| `M` | 開關區域地圖 |
| `Esc` | 關閉最上層視窗或開啟暫停選單 |
| 滑鼠滾輪 | 在允許範圍內縮放畫面 |

## 存檔與匯出

- 三個存檔欄與設定儲存在目前瀏覽器 profile 的 IndexedDB；不是 repo 內的檔案，也沒有可自訂的應用程式資料路徑。
- 手動匯出的存檔由瀏覽器下載至使用者選定的下載位置；匯入時由使用者透過檔案選擇器指定檔案。
- 清除瀏覽器網站資料會移除本機存檔；執行前應先匯出需要保留的存檔。
